# 🐾 PetRent

## ¿Cómo ejecutar el proyecto?

1. Clona el repositorio:
   git clone https://github.com/tu-usuario/petrent.git
   cd petrent

2. Instala las dependencias:
   npm install

3. Inicia el servidor de desarrollo:
   npm run dev

4. Abre el navegador en:
   http://localhost:5173
